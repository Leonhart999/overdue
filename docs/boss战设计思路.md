# 《逾期》Boss 战设计思路

本文记录 8 个头目（齿颚、卢克丝夫人、八头蛇、凯德主管、维斯珀、芮恩、刻洛、折尺）的设计思路、技能数值和战场设计。数值取自当前代码（2026-11-07）；规则全文以 `docs/GDD.md` 第 8 节为准。

---

## 0. 通用设计原则

1. **场地就是武器。** 每个场地至少 3 种机关，最大的伤害和最长的硬直几乎都来自场地，头目自己也会用或被场地伤到。
2. **读招 → 躲 → 惩罚。** 每招都有预告（红色区域/线/音效），预告范围不小于实际判定；招后有破绽。不靠随机伤害。
3. **每把武器都要有用武之地。** 电弧要有导体可以跳，霰弹要有东西可推、有软弹可清，刀要有值得弹回的子弹，钉枪要有可钉的表面和物体。
4. **一招一格血。** 只有大型、明显预告的招式才扣 2 格。没有躲不开的伤害。
5. **每个阶段都加新东西**，而不是只变快。

### 通用数值

| 项 | 数值 |
|---|---|
| 场次强化（第 1–4 场） | 生命 ×1 / ×1.35 / ×1.7 / ×2.0；预告与恢复 ×1 / 0.9 / 0.82 / 0.76；子弹速度 ×1 / 1.08 / 1.15 / 1.2 |
| 失衡上限 | 100 + 15 ×（场次 − 1）；2 秒不挨打后每秒回落 25 |
| 瘫痪 | 3 秒，期间受伤 ×1.5，打断当前招式 |
| 弱点 | ×1.3（战术目镜 ×1.8，且所有预告 +15%） |
| 骇入臂干扰 | 头目、它的子弹和预告整体减速到 ×0.7，持续 4 秒 |
| 阶段转换 | 期间无敌，不能被瘫痪；瘫痪中跨过阈值时，转换等瘫痪结束再播 |
| 出场动画 | 2.5–4.5 秒，纯视觉，可按空格/点击跳过 |

## 1. 齿颚 GEARJAW · 锈港压实场

**设计思路：教学关。** 体型最大、转身最慢，所有机制都直白可读：看预告、绕背、引它撞柱子、拉吊车。所有核心交互都排在中线上：吊车落点线、两根钢柱都在 x = 320，所以"引它撞柱 → 立刻拉吊车"是设计好的连招。

**基础数值**：生命 4200；阶段阈值 60% / 25%；掉落液压拳。

### 战场（640×360，单屏）
| 机关 | 规则与数值 |
|---|---|
| 门式吊车 | 小车沿中线上下往返；拉杆在上下墙两端（E / 抓钩 / 骇入，骇入让小车先冲到准星高度）。0.85 秒后落下：**350 伤害 + 999 失衡（必瘫痪）+ 剥 2 块护甲**，落地的废铁块成为新障碍。12 秒后重新装货 |
| 钢柱 ×2 | 在中线上；被冲撞撞毁，齿颚瘫痪 |
| 废车堆 ×4 | 当墙用；被冲撞撞散，齿颚停 1 秒；爆炸 3 次或吊车也能砸散 |
| 油桶 | 引信 0.5 秒，爆炸半径 48：对头目 160 伤害 + 45 失衡 + 剥 1 甲，对玩家 1 格；钩索会把油桶拽回它身边 |
| 油槽 | 着火 4 秒，头目站在上面每秒 16 伤害 |
| 压实板（P3） | 左右墙各内推 48 px；按钮被打中/骇入 → 猛推 40 px：300 伤害 + 瘫痪，冷却 8 秒 |

### 招式
| 招式 | 预告 | 判定 / 伤害 | 说明 |
|---|---|---|---|
| 钩索 | 0.7 秒红线 | 1 格并拽到面前，接震地 | 钩速 560；钩到墙/柱后钢缆绷 1.3 秒，刀切断 → +45 失衡 |
| 冲撞 | 0.85 秒（连撞后续 0.5 秒），车道宽 70 | **2 格** + 击退 | 速度 400；撞柱 → 瘫痪；撞墙 → 1 秒破绽 |
| 废铁喷射 | 0.5 秒 | 3 波 × 9 发软弹，速度 160 | P3 加环形弹 |
| 震地 | 0.55 秒（内圈 40 + 外圈 150 的范围环） | 冲击环 30→150 px，0.65 秒，1 格 | 地面攻击，可跳 |
| 过热排气（P2+） | 1.1 秒，半径 76 | 1 格，点燃油槽 | 之后 2.6 秒"冷却中"，受伤 ×1.5 |
| 钩索横扫（P2+） | 0.8 秒扇形（半径 128，约 190°） | 1 格 | 不能跳过 |

**阶段**：P1 正面装甲（伤害 ×0.4，4 块甲板），背后引擎是弱点 → P2 剥甲、出招更快、连撞 2 次（第 3 场起 3 次）→ P3 压实板推进、冲撞留燃烧油迹、吊车每 8 秒补油桶。

## 2. 卢克丝夫人 MADAME LUX · 霓虹集市夜店

**设计思路：分辨真假 + 用她的光打她。** 她靠分身和全息投影制造混乱。玩家要学会三件事：断电让分身消失、打投影仪减少分身、转镜子把她的激光反射回去。场地做成两屏宽的三区夜店（吧台区、转盘舞池、VIP 区），让"在哪个区打"成为选择。

**基础数值**：生命 3250；阈值 65% / 30%；掉落相位步。

### 战场（1280×360，横向卷轴）
| 机关 | 规则与数值 |
|---|---|
| 配电箱 ×2（两头） | 打 / E / 电弧 / EMP / 骇入 → **全场断电 5 秒**：分身消失、转盘停、真身受伤 ×1.5。共用冷却 20 秒 |
| 全息投影仪 ×4 | 每台维持一个分身；打坏 / 过载 / 骇入 / E / 刀切电线 → 离线 15 秒 |
| 镜子 ×3（装在转盘上） | E / 霰弹 / 刀 / 骇入 / 钉子回收 → 转 45°。她的激光反射回她身上：**300 伤害 + 75 失衡** |
| 转盘舞池 | 半径 96，3 圈 × 8 格，跟 120 BPM 节拍亮格（预告 2 拍、伤害 1 拍，可跳）；转速 P1 0 / P2 20°/秒 / P3 40°/秒；放激光前停在 45° 整数角 |
| 打碟台 | 转盘反转 6 秒，冷却 12 秒 |
| 玻璃隔断 | 挡人和子弹；激光与法线夹角 ≤ 22.5° 时穿过，否则反射 |
| 追光灯 ×2 | 站在光里你的伤害 +25%；真身在光里有影子，分身没有 |
| 吧台、沙发 | 矮掩体：挡走路和软弹，不挡激光；跳跃腿能跳过 |

### 招式
| 招式 | 说明 |
|---|---|
| 飞吻 | 心形扩散软弹（分身也会放小号的） |
| 扇面 | 0.7 秒预告，5 道旋转弹流 |
| 换位 | 和最近的分身闪烁互换位置 |
| 追光闪爆 | 你站在光里时，光圈定住变红后爆开 |
| 聚光激光（P2+） | 预告 1 秒，画出完整反射路径；1 格；穿过分身会打掉它；血量低于 45% 时最后一发扫动 |
| 安可（P3） | 飘到转盘中心，每秒回复 2%（不超过 30% 线），同时放双螺旋弹幕 5 秒；期间失衡累积 ×3；断电或打满失衡可打断，之后冷却 14 秒 |

**阶段**：P1 2 个分身、转盘不转 → P2 3 个分身、舞池全开、加激光 → P3 4 台投影仪全开（同时最多 3 个分身）、转盘加速、安可。

## 3. 八头蛇 OCTOHYDRA · 下网淹水井道

**设计思路：目标优先级 + "烧焦"机制。** 头被打掉后 7 秒会长回来，除非把断颈烧焦，所以伤害本身不够，必须配合电水、爆炸或电弧。场地做成三层的纵向井道，整场战斗沿井道往上打，最后被核心追下来。

**基础数值**：核心生命 2400，每个头 160；每烧焦一个断颈，核心损失 5.5% 最大生命；阶段阈值由烧焦数决定（3 个 → P2，8 个 → P3）；瘫痪 2.6 秒；掉落骇入臂。

### 战场（640×1072，纵向卷轴，三层）
| 机关 | 规则与数值 |
|---|---|
| 浅水 | 移速 −15%；任何水面离格栅都不超过约 90 px（保证预告时间内能走出去） |
| 电缆接线盒（每层 1 个，顶层无） | 打 5 下 / E / 抓钩 / 骇入 / 过载 / 电弧持续 → 1.2 秒预告后**本层水面带电 1.5 秒**：玩家在水里扣 1 格（跳起免疫）；本层所有头 60 伤害 + 麻痹，本层断颈立即烧焦。冷却 14 秒 |
| 服务器机柜 | 挡光束和子弹，导电，抓钩锚点；撕咬头咬 3 次会坏 |
| 水闸 / 排水口 | P2 打开水闸，入口池淹成深水（掉进去扣 1 格）；P3 排水口打开，核心池排干 |

### 头与断颈
| 头 | 招式 |
|---|---|
| 喷吐头 | 抛物线酸液软弹，落点红圈（不小于判定半径 12），落地留 5 秒毒液 |
| 光束头 | 1.2 秒追踪预告后发硬光束，机柜挡得住；光束扫过断颈也会把它烧焦 |
| 撕咬头 | 直线扑咬（射程 150），扑完卡住 1 秒，受伤 ×1.5 |

断颈 7 秒后重长，长回来过一次的头再被打断就永久枯萎。烧焦方式：带电的水、爆炸/火、电弧过载、电弧持续电 1 秒、光束扫过。

**阶段**：P1 入口池 3 个头 → P2 水闸打开、4 个头、核心每约 11 秒自己给水通电（1.7 秒绿光预告）并向下扫低光束 → P3 核心护盾破碎、升起追你（不同层时每秒 92 px），环形弹幕 + 冲撞（2 格，撞机柜自晕 2.2 秒）；核心在水里时接线盒通电瞬间 200 伤害、带电期间每秒 70。

## 4. 凯德主管 DIRECTOR KADE · Skyline 区天台停机坪

**设计思路：绕开正面，拆掉他的支援。** 正面能量盾是这一战的核心问题，每把武器都有自己的解法；无人机和炮台是他的支援，也可以变成你的。直升机的下洗气流同时是威胁和庇护所。

**基础数值**：生命 3300；阈值 65% / 30%；掉落液压滑铲。

### 能量盾
- 正面 100° 挡住所有子弹和光束；刀砍盾被弹开（0.3 秒硬直）。背后 120° 是弱点（×1.3）。
- 各武器的解法：电弧从无人机/炮台/油桶跳过去，按那一侧结算；钉在盾上的钉子回收时把盾拽开 1 秒；霰弹弹丸打在盾上积累压力，**13 颗弹丸**把盾轰开 1.2 秒；独头弹和满蓄力液压拳也能打偏盾；弹回的子弹、过载、落地冲击、滑铲、爆炸和火无视盾；滑铲能钻到他身后。

### 战场
| 机关 | 规则与数值 |
|---|---|
| 直升机 | 每 18 秒悬停 6 秒；下洗气流把人、油桶、无人机、软弹向外推（硬弹不受影响） |
| 停机坪控制台 | E / 抓钩 / 骇入 / 过载：叫来或赶走直升机，冷却 20 秒；P3 强攻时使用 → 直升机坠向凯德：**380 伤害 + 999 失衡**，半径 60，你在里面扣 2 格 |
| 自动炮台 ×2 | 默认打你（0.8 秒红线后 4 连射）；骇入后 15 秒帮你打他；他会用"重置"夺回（造成 70 伤害可打断） |
| 探照灯 ×2 | 被照 2 秒 → "锁定"，他下一招追踪更久；独头弹、爆炸、过载、6 根钉子或 30 伤害打碎 |
| 护栏缺口 ×2 | 掉出去扣 1 格、被绞盘拉回（1.5 秒无敌）；无人机被打进去直接坠毁 |
| 燃料罐 ×2 | 爆炸半径 72，留下燃油火 |

### 招式
| 招式 | 说明 |
|---|---|
| 盾冲 | 车道预告，冲到撞墙/设备为止（撞后 1–1.3 秒背后空门）；撞到油桶/燃料罐会点燃而不是直接引爆 |
| 压制射击 | 扇形预告，软弹与硬弹交替 |
| 无人机包围 | 两架无人机绕你一圈，红线锁定后发射 |
| 封锁扫描（P2+） | 每 20 秒，红色扫描约 2.6 秒，结束时随机锁住你的腿或手臂 6 秒；扫描期间进过下洗气流、被炮台打中或他被瘫痪 → 扫描失效 |
| 跳劈（P2+） | 落点红圈 1 格 + 地面冲击环（可跳）；你的腿被封锁时他不用这招 |
| 直升机强攻（P3） | 两条红色扫射线 |
| 全面清场（P3，≤10%） | 12 秒倒计时，控制台锁定，直升机悬停在离他最远的位置（安全区）；结束时不在安全区扣 2 格；瘫痪他可打断，之后重新冷却 |

**阶段**：P1 盾 + 2 架无人机（被打掉 8 秒后重放）→ P2 加封锁扫描和跳劈 → P3 盾碎、出招快约 18%、直升机强攻、全面清场。

## 5. 维斯珀 VESPER · 环线列车车顶

**设计思路：视线、掩体和时机。** 她是狙击手，所以战斗围绕"看得见她的瞄准线"展开；地图做成 8 节车厢的长车顶，横向卷轴追逐。最大的输出机会来自场地：龙门架扫过时，在连接处外面被控住的那个人会被撞飞——让它是她而不是你。

**基础数值**：生命 2250；阈值 65% / 30%；掉落战术目镜。

### 战场（8 节车厢 × 370 px + 连接处 30 px，地图约 3220×360，横向卷轴）
| 机关 | 规则与数值 |
|---|---|
| 掩体（每节 2 个） | 挡狙击弹和瞄准线；3 发普通弹或 1 发穿甲弹打碎，剩下只挡软弹的碎块 |
| 龙门架 | 每 16 秒（P3 14 秒）从车头扫向车尾，带倒计时条和"安全"标记。你被撞：1 格 + 向车尾击退；**车厢连接处安全**。她在连接处外、或在连接处里被瘫痪/电晕时被撞：**360 伤害 + 999 失衡** |
| 接触网接线盒（每节 1 个） | 4 下 / E / 骇入 / 电弧 0.5 秒 → 2 秒预告后整节车顶放电 1.5 秒；只有开头 0.4 秒伤你（跳起或离开那节可躲）；她在上面：140 伤害 + 1.2 秒麻痹并打断狙击。冷却 10 秒 |
| 脱钩（P2+） | 约每 14 秒最后一节车厢脱钩（你在上面时预告 3–4.5 秒，空车 1.5 秒）；还在上面扣 1 格并被放到下一节；左墙随之前移，最少留 3 节 |
| 隧道（P3） | 只剩 3 节时进入，画面变暗，只有瞄准线、你身边、接线盒和警示灯亮着 |

### 招式
| 招式 | 说明 |
|---|---|
| 狙击 | 红线追踪 1.0 秒 → 锁定变白 0.35 秒 → 硬弹（速度 560，1 格）。刀/液压拳打回去命中她：**伤害 ×5 + 42 失衡** |
| 换位 | 烟雾 + 跳到 1–2 节外的落点（落点红圈提前显示，屏幕外有边缘标记）；你靠近她约 5 秒（P2 4.2、P3 3.4）后触发 |
| 近身踢 | 你离她 50 px 内，0.45 秒扇形预告，1 格 + 击退，之后后空翻拉开 |
| 三连点射（P2+） | 三条散开的瞄准线收拢到你身上后依次开火 |
| 穿甲弹（P2+） | 粗金色线，画出穿过第一个掩体后的真实路径 |
| 地雷（P2+） | 每次换位留 1 颗（最多 3 颗，不放在连接处）；靠近 0.4 秒引爆，120 伤害半径爆炸；霰弹/爆炸可提前引爆 |

**各武器**：钉在她身上的钉子让瞄准变慢，每根 −8%，最多 −40%；电弧沿接触网/接线盒跳到她身上（伤害 ×1.5）；独头弹击退约 45 px，可以把她推出连接处；抓钩射程 250，能直接拉到她身边；骇入臂让瞄准线乱晃 4 秒（锁定后停止晃动）。

**AI 时机**：她只在"出招时间 + 走回连接处的时间（约 1.3 秒）"小于龙门架到达时间时出招，所以被撞几乎总是玩家造成的结果。

## 6. 潜网客·芮恩 WREN · 深潜网吧

**设计思路：同一张地图的两层世界。** 前面五场都在一层空间里，这一场把"空间"本身变成机制：现实层和网络层共用坐标，但墙、机关和敌人都不同。你的身体留在潜入舱里，潜网带来进攻机会，也留下破绽。核心是两层之间的取舍与心理博弈：什么时候下去拆盾，什么时候上来保护身体，以及 P2 她也潜网时，你是去网络层追她的分身，还是回现实打她毫无防备的身体。

**形象**：黑色侧剃短发、一缕青色挑染，青色 AR 单片镜，胸前 6 格发光数据卡匣，品红内衬的无袖长风衣，右臂义体，手持触笔。立绘由用户原画经 `tools/pixel-tools` 转成 112×144 游戏色板像素图（`src/art/actors/wrenStandee.ts`），破损版在原图上做故障错位和碎裂单片镜。

**基础数值**：生命 1300（护盾期间伤害 ×0.2，实际有效生命远高于数字）；阈值 62% / 25%；掉落骇入臂。

### 战场（960×540，横纵双向卷轴）
| 层 | 内容 |
|---|---|
| 现实层 | 地下黑网吧：4 组卡座、吧台、2 台服务器机柜（导电、挡子弹）、3 个油桶、四角 4 台潜入舱、顶部中间她自己的舱 |
| 网络层 | 同一块地面的青绿线框：8 段防火墙，位置和现实家具不同；4 条单向**数据流**（每秒 150 px，带走人和数据针）；端口位；4 个出口节点（对应潜入舱） |

两层都有 16 px 的寻路网格，她和自动驾驶用它绕墙。

### 核心规则
| 规则 | 数值 |
|---|---|
| 潜网 | 舱边按 E，0.5 秒后进入网络层，身体留在舱里；切换期间不能移动和开火 |
| 退出 | 任一出口节点按 E，0.4 秒后退出，**身体被传到那台舱**（网络层可当近路） |
| 层隔离 | 不在你这一层的物体会被移出碰撞、画成残影；她的子弹和预告带层标签，只在同层生效 |
| 拔线 | 你潜网后她扫描 1.2 秒，走到你的舱；1.4 秒预告（舱上红圈、警报、屏幕红边、倒计时、边缘标记）→ 扣 1 格 + 强制退出 + 0.6 秒硬直；被拔线的舱离线 5 秒 |
| 防火墙护盾 | 现实层受伤 ×0.2、不积累失衡；P1 3 个端口，P2 4 个（光束更快）；端口生命 100 × √场次倍率，各有 2 道旋转哨兵光束（出现时闪 1 秒） |
| 护盾崩溃 | 端口全灭 → 瘫痪 2 秒，之后 10 秒正常受伤，然后端口重生 |
| 跨层 | 骇入臂在现实层直接骇掉端口；电弧过载电球打掉端口 |

### 招式
| 招式 | 层 | 说明 |
|---|---|---|
| 触笔速射 | 现实 | 三条红线预告 0.6 秒，3 根硬数据针，1 格，可被刀和液压拳弹回 |
| 全息弹窗 | 现实 | 3–5 个矩形窗口预告 0.9 秒后砸下，1 格，可跳过 |
| 数据流改向 | 网络 | 她去拔线途中每 5.5 秒一次：箭头闪红 1 秒后反转 |
| 代码鞭（P2+） | 网络 | 分身的扇形攻击，预告 0.7 秒 |
| 数据针（P2+） | 网络 | 分身发射的软弹，霰弹可清 |

### 阶段
- **P1（100%–62%）**：她在现实层，护盾 + 3 个端口；你潜网拆盾，她去拔你的线。
- **P2（62%–25%）·她也潜网**：你潜网时，她走到自己的舱躺下，代码分身在网络层追你（打分身 = 打她）。她在舱里的身体**受伤 ×1.5**、无视护盾。被你打到、你靠近到 90 px 内、或过了 7 秒，她 1.5 秒后醒来；10 秒后才能再潜网，期间继续拔线。端口 4 个。
- **P3（25%–0%）·强制断网**：端口消失、护盾永久下线、潜入舱关闭。所有人每 8 秒强制换层（屏幕中央倒计时，最后 3 秒放大）；落在墙里会被推到最近的空格。换层前她把全息弹窗放进下一层：先显示淡轮廓，换层 0.6 秒后砸下。

**出场**（3.3 秒）：网吧灯光闪烁，三个 AR 窗口弹出，她从舱里起身走下来，单片镜闪亮。

### 各武器
电弧沿机柜、潜入舱、端口跳转，过载电球直接打掉一个端口；钉子能钉在端口上回收；霰弹清网络层的数据针；刀弹回触笔针；抓钩在网络层钩防火墙节点快速移动。

### 实测（第 1 场）
| 武器 | 无敌 Bot 用时 | 普通 Bot（5 局） |
|---|---|---|
| 钉枪 | 约 91 秒 | 赢 4 局 |
| 电弧枪 | 约 119 秒 | 赢 4 局 |
| 霰弹枪 | 约 84 秒 | 赢 5 局 |
| 单分子刀 | 约 65 秒 | 赢 5 局 |

钉枪和电弧枪超出 55–85 秒的目标，主要是自动驾驶每 2 秒才按一次 E，在舱和节点边浪费时间，不代表真人体验。

### 已知问题
- 爆炸、电容脉冲和霰弹弹丸仍能清掉另一层的软数据针（清弹逻辑在共用引擎代码里）。
- "拔线"字样显示在你在网络层的位置，而不是舱上。

## 7. 校时员·刻洛 KAIRO · 记忆备份站

**设计思路：让玩家通过场景读出时间，再用行动拆解节奏。** 普通阶段要改变奔跑路线、处理旧轨迹和交错钟摆；加速阶段围绕追秒连斩考验完美闪避；迟滞阶段则让熟悉的动作变慢。时间变化有天光、钟针、环场灯序三组可观察的证据。加强的重点是补足普通与迟滞阶段的持续压力，保留加速连斩的核心地位。

**基础数值**：生命 4700；阶段阈值 65% / 30%；韧性上限为通用值 ×1.3（第一场 130），回落规则保留；掉落反射加速器。

### 时间与场地

| 项目 | 规则 |
|---|---|
| 场地 | 单屏 640×360；后墙独立于地板，可行走区 (24,104,592,236)，角色不能走上后墙 |
| 加速 | 开战先用一次，P1 不重放、P2 禁用，P3 转换后优先使用并恢复领域轮换；头目与敌对攻击 ×2.2，玩家原速，持续 9 个场景秒。昼夜约 2.25 秒一轮，钟针 ×36、灯序 ×12 |
| 迟滞 | P2 仅使用此领域，P3 与加速轮换；玩家动作、冷却和己方弹丸 ×0.55，头目原速；钟针停止、灯序 ×0.12 |
| 校时护摆 | 蓄势至少 1.2 秒，期间受到伤害 ×0.6；领域不能在现有敌对攻击中途突然开启 |
| 记录终端 | 封存尚未开始的敌对回放，再次使用释放玩家反击：220 伤害、65 失衡 |
| 时间断路器 | 解除领域与蓄势、暂停敌对记忆攻击 2.5 秒，冷却 10 秒 |
| 冷却喷流 | 0.75 秒预告、半径 76，120 伤害并必定瘫痪，冷却 12 秒 |

骇入与领域倍率相乘。**加速会缩短骇入在场景时间里的持续长度，也会加快失衡回落**，这两项按用户要求保留。常规警告在加速中仍至少保留 0.7 个场景秒；归档快门按实际回程路程延长警告。瘫痪解除领域，未在运行的领域不会被连续瘫痪反复推迟。

### 攻击结构

| 招式 | 作用与读法 |
|---|---|
| 滴答 | 基础间隔 P1/P2/P3 为 1.05/0.95/0.8 头目秒，每次提前画瞄准线；硬秒针可弹回。P2 或迟滞中追加提前量针，直线跑不再万能；每隔数格改为软弹报时 |
| 逆行残像 | 录下玩家路径后倒放，P3 追加第二道残像；提醒玩家不要绕小圈把危险轨迹堆在一起 |
| 停表 | 在预测位置画收拢表盘；闭合时仍在圈内会停住 0.7 个场景秒，于 0.6 秒处受 1 格伤害。转向、停步或闭合时闪避可躲，精准闪避可返还冷却 |
| 摆锤 | 贴近触发半径 58 的攻击；P2 起追加 58–92 环带回摆，需要改变逃离方向 |
| 借秒钟摆 | 实体秒针扫过场地，可用刀切断并封存；P2 起加一条更长、反向旋转的分针，P3 两者都回放 |
| 归档快门 | P2 起要求回到约两秒前的位置；危险着色只覆盖地板，不涂后墙。原始和回放都不叠加其他攻击 |
| 追秒连斩 | 加速专属，5/6/7 拍交叉斩；临出手转白锁定，要求读拍完美闪避。末拍故意延迟，每拍只扣 1 格；组末约一秒恢复，受伤 ×1.3 |

只在剩一份非快门延迟回放时叠加新原始攻击，最多同时两项，叠加间隔至少 3 秒。停表抓住玩家后清除附近敌弹，取消、转阶段、瘫痪或战斗结束立即释放控制，避免失去操作后再承受无提示攻击。

**武器关系**：刀处理可切钟摆与可反弹硬针；霰弹清报时软弹并推桶；电弧借机柜和机关传导；钉枪利用机柜、油桶与反击恢复期。三件机关提供远程触发和近身操作两种路线。

## 8. 建筑师·折尺 FOLD · 模块建筑工地

**设计思路：房间既是载具，也是压机。** 保留滑轨房带走人物、物体和地面部署物的特色，让合拢真正改变玩家下一步该站哪里。隔墙能挡一部分火力，但他会吊运越墙、投束越墙、沿预告折线发射测距弹。大的瘫痪窗口来自玩家引导他撞障碍、切吊索、启动压机和制动器。

**基础数值**：生命 4200；阶段阈值 65% / 30%；掉落滑铲腿。

### 空间规则

- 地图 880×608，四间 280×168 的房间围着中央工作区；每面后墙留门洞，中央和外侧通道保留退路。
- 横向每边滑动 72 像素，纵向每边滑动 48 像素；合拢需要预告，0.4 秒关闭，短暂保持后 0.6 秒归位。
- 站在房间上被带走，留在预告通道里被挤压：头目操作扣 2 格，玩家调度台操作扣 1 格。P3 可同轴整线合拢。
- 柱子、桶、设备、落梁、落钉、地面电球和地雷随地板移动；飞行物和空中人物保留自己的运动。墙体与画面同一步更新，结束战斗后房间仍会完成归位。

### 招式与反制

| 招式 | 压力 | 玩家制造的机会 |
|---|---|---|
| 测距连射 | P1/P2/P3 每组 2/3/4 发，最多 1/2/2 次墙面反弹，完整预告折线与折点 | 刀或液压拳弹回，伤害 ×2、追加 18 失衡 |
| 定尺冲锋 | 最多 380 像素，P2 起可能回身再冲 | 诱导撞立柱、设备、桶或落梁；普通墙只会停步 |
| 吊运 | 跨房追击，半径 46 落地伤害及扩至 112 的低空冲击波；P2 加软弹环，P3 接冲锋 | 起跳、闪避、刀切吊索或开制动器；中断后落在无墙位置 |
| 落梁 | 在玩家位置落下 1/2 根梁，临时改变射线与走位 | 梁可导电、抓钩、挡冲锋；独头弹、爆炸和拔刀可破坏 |
| 铆钉束 | 越墙投掷后散成软弹，不能靠同一面墙一直站桩 | 换位或用霰弹清弹，利用投掷间隙反击 |
| 落锤与尺扫 | 落锤逐个预告，近身尺扫阻止贴身站桩 | 落锤可跳，尺扫有明确扇形与恢复 |
| 通道合拢 | 大范围通道预告，再用小落锤压住最近出口 | 走上房间被带走，走其他出口，或在预告期瘫痪他 |
| 十字切割 | P3 横、纵依次预告锁定，切线宽 24 | 跳过或顺序离开，不同时封死两个方向 |

### 机关

| 机关 | 反用效果 |
|---|---|
| 四个调度台 | 1.2 秒预告后合拢对应通道，冷却 10 秒；夹到折尺造成 220 环境伤害与 3 秒瘫痪 |
| 紧急制动器 | 房间归位；抓住房间上的折尺、冲锋或吊运，80 伤害与 2.6 秒瘫痪，冷却 12 秒 |
| 中央装配压机 | 136×88 压区，预告 1.1 秒；260 伤害、3 秒瘫痪、破甲，玩家在内也受 1 格，冷却 14 秒 |
| 每房立柱与油桶 | 立柱不被他撞毁，持续作为反制点；油桶被毁后 16 秒补充，不在人脚下或合拢中生成 |

**各武器**：钉枪与地雷可提前部署在房间上；电弧沿梁、柱、控制台跳转；霰弹推桶、清软弹，独头弹拆梁；刀切吊索和反弹测距弹。地板运动把这些选择带到新的位置，鼓励玩家先布置，再诱导。
