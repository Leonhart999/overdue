逾期场地图纸

三张现有头目场地的重做方案，加上账簿（最终头目）场地的草图。所有图都按游戏里的实际尺寸画：屏幕 640×360，一格 16 px，可走区是第 1–38 列、第 3–20 行。

更新（2026-11-06）：卢克丝和八头蛇后来改成了卷轴大地图，本页 8.2、8.3 的单屏方案作废，以 GDD 8.2（横向夜店 1280×360）和 8.3（纵向井道 640×1072）为准。齿颚的压实场按本页实现。

保持单屏、固定镜头所有预告都要在屏幕里，这是“读招 → 躲 → 惩罚”的前提。地图变有趣靠形状和变化，不靠变大。
每张图换外形，再加一个会变的东西齿颚：压实板往里推。卢克丝：转盘会转。八头蛇：闸门和水位。

  1. 三张图的可走区域完全一样：都是 bounds: { x: 16, y: 48, w: 608, h: 288 } 的长方形，区别只在道具。
  2. 场地从头到尾不变。阶段变化只发生在头目身上。齿颚的 4 根柱子撞完以后，P3 是一块空地。
  3. 墙是安全的。贴墙绕圈能躲掉大部分招式；四个直角反而是被冲撞夹死的地方。
  4. 左右完全对称，玩家没有“去哪一边”的选择。卢克丝的三面镜子排成一条直线，能用的反射角很少。
方法

改造原则

1. 形状跟着头目的招式走冲撞型要车道和挡车点，光束型要角度和反射面，召唤型要分区。Hades 的阿斯特里昂撞上柱子会把柱子撞碎并伤到自己，场地就是按这个招式摆的。
2. 每个阶段改一次地形看得见、不可逆。挺进地牢的 Treadnaught 柱子被打掉后空间变大、掩体变少；Cannon 砸地会把地板砸成坑。
3. 不留永久安全点Wayfinder 的 Omen 上线后玩家都挤在场地中间躲，开发者改成让更多落地物刷到中间。
4. 掩体少而大，可以被拆The Level Design Book：掩体通常越少越好，头目战可以几乎没有；四面都能用的独立掩体适合一对一。
5. 场地大小跟头目体型配Wayfinder 把 Omen 的场地缩小、把她放大，让轮廓占满画面，压力更大。
6. 地面只分两三层The Level Design Book 建议把高度合并成少数几层。俯视角没有真高度，就用“地面 / 水 / 坑”三层。

8.1 齿颚 GEARJAW

压实场

现在吊车绕整个场地转一圈，冲撞在哪里引都一样，位置没有选择。改后吊车只走中线，车道用废车堆隔出来，齿颚越撞场地越空；P3 两侧压实板往里推，压实板自己变成新的挡车点。

P1

四个废车堆 + 两根钢柱，三条车道。

P2

护甲炸飞时掀翻上面两个废车堆，场地变空。

P3

柱子和车堆基本没了，两侧压实板各推进 3 格。

元素规则怎么用
吊车轨道小车沿 x = 320 上下往返（y 96–288），落点永远在中线上。拉杆移到轨道两端（上墙、下墙）。骇入：小车先冲到准星的高度，再给正常预告。把齿颚引到中线上，最好让它在线上瘫痪。
钢柱 ×2放在轨道上：(320, 128)、(320, 272)。撞上瘫痪 3 秒，柱子毁掉（不变）。撞柱的位置就在落点线上，撞柱 + 落吊车是设计好的连招。只有两根，用掉要想好。
废车堆 ×43×2 格，挡子弹和钩索。冲撞撞上：车堆散架，齿颚停 1 秒（不瘫痪）。爆炸 3 次也会散。P1 当掩体、隔车道；被撞掉以后场地越来越空。
油槽 ×2中车道上落点线两侧，各 5×1 格。点着烧 4 秒（同现在的油渍）。让它沿中车道冲过油槽，再点火。
油桶 ×5规则不变，位置改到车堆和墙角附近。推、抓、钉过去炸它。
压实板（P3）进入 P3 时左右墙闪 2 秒预告，各向内推 3 格（48 px），可走宽度 608 → 512。冲撞撞上压实板卡住 2 秒；压实板上的红色按钮被打中，压实板再猛推一次：300 伤害 + 瘫痪。推进时夹到的油桶直接爆炸。P3 时柱子和车堆基本没了，压实板接替挡车点。

要用的工具T1 外形遮罩T5 可破坏掩体T2 地形变化（压实板）

8.2 卢克丝夫人 MADAME LUX

转盘夜店

现在她在上、玩家在下，基本是上下对峙；镜子排成一条线。改后中间换成会转的圆形舞池，镜子装在转盘上跟着转，激光反射变成看时机的事；两侧包厢让“关投影仪”变成要走进角落的决定。

P1

转盘不转。先学镜子反射。

P2

转盘以 20°/s 转，镜子跟着转。

P3

她站在中心回血，外圈整圈亮，把人挤到她身边。

元素规则怎么用
转盘舞池半径 88 px，圆心 (320, 216)。3 圈 × 8 扇区 = 24 格，按节拍亮：亮 2 拍后伤害 1 拍（地面攻击，可跳）。P2 起以 20°/s 旋转，站在上面的人和物体跟着转（外缘约 30 px/s）。扇区转着扫过来，要看准时机走出去或跳过去。
镜面柱 ×3装在转盘外圈（半径 72，间隔 120°），跟着转盘转。E 仍然每次转 45°。激光预告和发射期间转盘暂停，所以预告线就是最终路径。等镜子转到合适角度再引她放激光，或者自己转镜子。
包厢 ×4两侧墙加厚 3 格，各留两个 3×4 格的凹位（深 48 px，一次冲刺能出来）。每个包厢一台投影仪和一张矮沙发（挡软弹，不挡光束）。要关某个分身，就得走进对应的包厢。
DJ 台舞台下沿中间 (320, 112)。E / 骇入：转盘反转或停转 6 秒。离她最近，去按要冒险。
配电箱 ×2、追光灯 ×2规则不变。配电箱从墙角往里挪到 (80, 60)、(560, 60)。断电时转盘也停。

要用的工具T1 外形遮罩T4 移动地面（转盘）舞池从方格改成扇区（club.ts 内部）

她的三个激光点位 MARKS 要按新镜子位置重新摆，保证每个点位至少和两面镜子成 0°/45°/90°。

8.3 八头蛇 OCTOHYDRA

三池机房

现在是一整片浅水，接线盒一拉全场带电，三个阶段水面一样。改后用走道把水分成三池：在哪个池子砍头、开哪道闸门，就是这场的空间决策，正好对上它的教学点“目标优先级”。P2 三池连通，回到现在的玩法；P3 排水，越打水越少。

P1

三池分开，闸门关着。

P2

核心撞开两道闸门，三池连成一片。

P3

核心升起，中池变成排水口，水往里退。

元素规则怎么用
三个水池第 13–14 列、第 25–26 列是 32 px 宽的干走道（第 6–17 行），把水分成左、中、右三池。第 18–20 行是干走道（出生点）。决定在哪个池子里砍头：断颈留在原地。
闸门 ×2每条走道中间（第 11–12 行）一道。阀门：E / 骇入 / 打 3 下，1 秒后开或关。开着时那 2×2 格变成水，两边的池子连通，走道也断开（要蹚水或跳过去）。想电中池就得先开闸门。
接线盒 ×2左边的只电左池，右边的只电右池，再加上闸门连着的池子。中池没有接线盒。伤害数字不变。把撕咬头引到有接线盒的池子里再砍。
服务器机柜 ×3每池一个，放在干垫子上（规则不变）。
核心凹槽上墙中间挖进去 10×3 格，核心待在里面。两边上墙加厚到第 5 行。场地有了一个明确的“上方”。
排水口（P3）中池出现 4×3 格的坑。40 秒内水从外圈往排水口退，水里有朝排水口的水流（25 px/s）。掉进坑扣 1 格，回到坑边。核心在水里时接线盒伤害很大（现有规则），所以要趁水还没退完打。

要用的工具T1 外形遮罩T2 地形变化（闸门、水位）T3 坑T4 移动地面（水流）

这张最贵。8 个出头点按三池重新分配：左池 3 个、右池 3 个、中池 2 个。

8.5 之后的里程碑

账簿的清算大厅

凯德的天台已经在 GDD 8.4 里单独设计（护栏缺口、直升机下洗气流、炮台、探照灯塔），这里不再重画。它要用的系统和下面的工具对得上：护栏缺口用 T3 坑，下洗气流用 T4 移动地面。

  • 地面是 12×6 的大格子。“审计”先像表格选中一样高亮一整行或一整列，2 秒后把这些格子改写成前面场地的地形：钢柱格、水格、舞池格、坑格。
  • 全部用 T1–T4 拼出来，不需要新系统。改写那一刻用骇入臂的字符画效果。
工程

要加的五个工具

工具内容成本谁用
T1 外形遮罩每个场地写一张 40×23 的字符遮罩。背景贴图本来就是用 isWall(x, y) 按格子生成的，现在让碰撞墙也从同一张遮罩生成（把墙格合并成矩形加进 w.walls）。小全部
T2 地形变化战斗中把一块格子改成墙 / 地 / 水 / 坑：先闪黄黑条纹 + 警报音，再生效；背景上叠一张对应贴图。中压实板、闸门、水位、账簿
T3 坑玩家走进去扣 1 格，1 秒后回到最近的安全格，无敌 1 秒。冲刺途中经过坑不掉，终点落在坑里才掉；跳跃可以越过。道具掉进去消失，头目各自定义。中八头蛇 P3、凯德、账簿
T4 移动地面区域内的人和物体每帧被平移：传送带、转盘、水流用同一套。小卢克丝、八头蛇 P3、凯德
T5 可破坏掩体有血量的固体道具，挡子弹；被冲撞或爆炸拆掉后留下碎片贴图。小齿颚

建议顺序

  1. T1 + T5 + 压实场。齿颚是参考实现，先验证工具。
  2. 试玩，确认方向。
  3. T4 + 转盘夜店。
  4. T2 + T3 + 三池机房。
  5. 凯德的天台直接用 T3、T4；账簿的清算大厅用全部工具。

每一步都要让 tests/sim.test.ts 的机器人打完全部 头目 × 武器 组合，并对比改前改后的通关时间。
